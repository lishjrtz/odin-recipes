The current project is to develop a basic recipe website consisting of a main
index page that links to a few different recipe pages

The purpose of this project is to apply and practice what I have learned thusfar
about using HTML.

The skills this project will demonstrate include:

    - Proper document and file organization to ensure coherent pathing across links
    - Standard and comprehensive HTML boilerplate information for all pages
    - Utilization of headings, paragraphs, bolding, italicization, lists, and other tools in text organization
    - Knowledge and application of both absolute and relative links to other pages and to images
    - The creation of a consistent and intentionally-rendered Git commit log
